# Plan 02-01: Journey Schema, Step Machine Topology & Validation Engine

## Goal

Establish the foundational data structures, state machine topology, typed visa catalog, formatting utilities, validation predicates, and resumption selectors required for the Phase 2 guided journey stages.

## Tasks

### 1. Visa Catalog & Recommendation Model

- Create `src/features/visa/types.ts` defining:
  - `DestinationCountry`: `'USA' | 'UK' | 'Canada' | 'Australia' | 'Schengen'`
  - `TripPurpose`: `'tourism' | 'business' | 'study' | 'work'`
  - `VisaItem`: `id`, `name`, `category`, `description`, `destination`, `purposes`, `visaFee`, `govtFee`, `platformFee`, `totalCost`, `processingDaysMin`, `processingDaysMax`, `processingTimeDisplay`, `requiredDocuments`, `isRecommended`
- Create `src/features/visa/catalog.ts`:
  - Implement full visa dataset (e.g. USA B1/B2, F1, H1B; UK Standard Visitor, Student, Skilled Worker; Canada Visitor, Study, Work; Australia Tourist, Student, Work; Schengen Tourist, Business).
  - Implement `getVisaOptions(destination, purpose)` returning ranked list of matching visas with `isRecommended` flagged on the top match.
  - Implement `getVisaById(id)`.
- Create `src/features/visa/catalog.test.ts` to test lookup, fee math, and recommendation matching.

### 2. Formatters & Validators

- Create `src/features/wizard/formatters.ts`:
  - `formatPassportNumber(input: string): string` — uppercases, strips non-alphanumeric, limits to 9 chars (`AA1234567`).
  - `formatPhoneNumber(input: string): string` — ensures `+91 ` prefix, formats 10 digits as `+91 XXXXX XXXXX`.
- Create `src/features/wizard/validators.ts`:
  - `isValidPassport(passport: string): boolean` (`^[A-Z]{2}\d{7}$`).
  - `isValidPhone(phone: string): boolean` (`\d{10}`).
  - `isValidEmail(email: string): boolean`.
  - `getPassportExpiryStatus(expiryIso: string, travelIso?: string): { isValid: boolean; isNearExpiry: boolean; message?: string }` (checks < 6 months from travel date or now).
  - Constructive error message generator: `getErrorMessage(field: string, errorType: string): string` providing specific fixes (e.g., "Passport number must start with 2 letters followed by 7 digits, e.g. AA1234567").
  - Sub-step validators: `validateVisaSelectionStep`, `validateIdentityStep`, `validateContactStep`, `validateVisaSpecificStep`.
- Create `src/features/wizard/validators.test.ts` and `src/features/wizard/formatters.test.ts`.

### 3. Wizard Machine & Step Topology

- Update `src/features/wizard/types.ts` and `src/features/wizard/machine.ts`:
  - Define `StepId = 'visa-selection' | 'personal-identity' | 'personal-contact' | 'personal-details' | 'documents' | 'review-payment' | 'confirmation'`.
  - Define `JOURNEY_STEPS` with human readable labels, stage numbers (1–5), and time estimates.
  - Expand XState machine with `NEXT`, `BACK`, `GOTO`, `ANSWER_CHANGED`, `RESET` events.
- Update `src/features/wizard/selectors.ts`:
  - Implement `deriveStepStatus(stepId, answers, currentStepId)` using sub-step validators.
  - Implement `getFirstIncompleteStep(answers)` to find the earliest incomplete step for `STATE-04`.
  - Implement `deriveProgress(answers)` returning completed step count and estimated minutes remaining.
- Update `src/features/wizard/selectors.test.ts` and `src/features/wizard/machine.test.ts`.
