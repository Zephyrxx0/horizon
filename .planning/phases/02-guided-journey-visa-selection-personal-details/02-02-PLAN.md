# Plan 02-02: Error Summary Component & Form UX Primitives

## Goal

Build reusable, accessible UI primitives for top-of-page error summaries (`ERR-01`), passport expiry warnings (`PERS-05`), and on-blur field validity checkmarks (`PERS-06`).

## Tasks

### 1. Accessible Error Summary Component (`ERR-01`, `ERR-02`)

- Create `src/components/ui/ErrorSummary.tsx`:
  - Props: `errors: Array<{ fieldId: string; label: string; message: string }>`, `title?: string`, `autoFocus?: boolean`.
  - DOM structure: `div` with `role="alert"`, `aria-live="polite"`, `aria-labelledby="error-summary-heading"`.
  - Heading: "There is a problem" / "Please correct the following errors".
  - List of links `<a href="#{fieldId}" onClick={handleClick}>` that call `document.getElementById(fieldId)?.focus()` and `scrollIntoView({ behavior: 'smooth', block: 'center' })`.
  - Clean error styling with red border, calm background, and high contrast icon.
- Create `src/components/ui/ErrorSummary.test.tsx` with unit and `vitest-axe` tests.

### 2. Contextual Passport Expiry Warning Card (`PERS-05`)

- Create `src/components/ui/ExpiryWarning.tsx`:
  - Props: `expiryDate: string`, `confirmed: boolean`, `onConfirmChange: (confirmed: boolean) => void`.
  - Amber alert banner with warning icon, plain-language text: "Your passport expires on {formattedDate}. Most countries require at least 6 months validity. You may want to renew first."
  - Checkbox: "I understand the 6-month validity requirement and wish to continue anyway".
- Create `src/components/ui/ExpiryWarning.test.tsx` with unit and `vitest-axe` tests.

### 3. Enhance Field Component for Green Checkmarks (`PERS-06`)

- Update `src/components/ui/Field.tsx`:
  - Add `isValid?: boolean` prop to show a green checkmark icon when the field has passed validation after blur.
  - Ensure `aria-describedby` links error, hint, and validation state properly.
- Update `src/components/ui/Field.test.tsx` to verify green checkmark rendering and axe accessibility.
- Update `src/components/ui/index.ts` to export new primitives.

## Verification

- `pnpm vitest run src/components/ui/` passes with all tests and zero axe violations.
