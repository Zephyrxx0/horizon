# Plan 02-03: Stage 1 — Visa Selection & Recommendation Screen

## Goal

Implement Stage 1 (Visa Selection & Recommendation) allowing applicants to select their destination and trip purpose, review recommended visa options with transparent itemized pricing and required document checklists, and select their visa with confidence.

## Tasks

### 1. VisaCard Component (`SELCT-02`, `SELCT-03`, `SELCT-04`)

- Create `src/features/visa/VisaCard.tsx`:
  - Props: `visa: VisaItem`, `isSelected: boolean`, `onSelect: () => void`.
  - Render visa name, category description, and "Recommended" badge if `visa.isRecommended`.
  - Render processing duration with clock icon (e.g., "5–7 business days").
  - Render transparent fee breakdown table:
    - Visa Fee: ₹X,XXX
    - Government Fee: ₹5,000
    - Platform Fee: ₹1,500
    - **Total: ₹XX,XXX**
  - Render upfront document checklist:
    - "Required documents for this visa:"
    - List of documents (e.g., Passport Pages 1–2, Recent Photograph, Bank Statement, Invitation/Admission letter).
  - Select button with 48px touch target and clear selected indicator (`aria-checked`).
- Create `src/features/visa/VisaCard.test.tsx` with unit and `vitest-axe` tests.

### 2. VisaSelectionScreen Component (`SELCT-01`, `SELCT-04`)

- Create `src/features/visa/VisaSelectionScreen.tsx`:
  - Destination country selector (`Select` component with USA, UK, Canada, Australia, Schengen).
  - Purpose selection (`RadioCard` or pill group with Tourism, Business, Study, Work).
  - Reactive visa list container rendering `VisaCard` components for matches.
  - Form validation on continue: prompt if country or visa is unselected.
  - "Save & Continue to Personal Details" button dispatching `ANSWER_CHANGED` and `NEXT` to the wizard machine.
- Create `src/features/visa/VisaSelectionScreen.test.tsx` testing interaction, filtering, selection, and a11y.
- Export all from `src/features/visa/index.ts`.

## Verification

- `pnpm vitest run src/features/visa/` passes with all tests and zero axe violations.
