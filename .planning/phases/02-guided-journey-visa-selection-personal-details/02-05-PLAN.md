# Plan 02-05: Guided Journey Integration, Step Navigation & E2E Verification

## Goal

Integrate Stage 1 (Visa Selection) and Stage 2 (Personal Details) into the main application shell, add the "Continue Application" draft resumption banner (`STATE-04`), and author comprehensive Playwright E2E tests validating the complete journey.

## Tasks

### 1. Resume Banner Component (`STATE-04`)

- Create `src/components/ResumeBanner.tsx`:
  - Detects if answers exist in localStorage and computes `firstIncompleteStep` via `getFirstIncompleteStep(answers)`.
  - If a draft is in progress and user is on a different step or start screen, renders banner: "You have an application in progress for {visaName || 'Visa'}. [Continue Application] [Start Over]".
  - "Continue Application" jumps directly to the first incomplete step.
  - "Start Over" resets draft answers with confirmation.
- Create `src/components/ResumeBanner.test.tsx` with unit and `vitest-axe` tests.

### 2. Main App Journey Wiring

- Update `src/App.tsx` and `src/components/AppShell.tsx`:
  - Replace demo wizard steps with the full 5-stage journey.
  - Render `VisaSelectionScreen` when `currentStepId === 'visa-selection'`.
  - Render `PersonalDetailsScreen` when `currentStepId` is any of `personal-identity`, `personal-contact`, `personal-details`.
  - Render placeholders for Stage 3 (Documents), Stage 4 (Review & Payment), and Stage 5 (Confirmation).
  - Connect `ProgressStepper` to real derived statuses from `deriveStepStatuses(answers, currentStepId)`.
  - Display `ResumeBanner` at top of journey when draft resumption is available.
- Update `src/App.test.tsx` to verify full shell integration and step navigation.

### 3. Playwright E2E Test Suite

- Create `tests/e2e/phase2-guided-journey.spec.ts`:
  - **Scenario 1: Complete Stage 1 & Stage 2 Flow**:
    - Select USA → Tourism → B1/B2 Visa.
    - Check upfront cost breakdown (₹7,500 + ₹5,000 + ₹1,500 = ₹14,000) and document checklist.
    - Advance to Stage 2a (Identity): enter Name, DOB, Passport number (verify `AA1234567` formatting).
    - Advance to Stage 2b (Contact): enter Email, Phone (verify `+91` auto-prefix).
    - Advance to Stage 2c (Visa Details): enter US travel dates and contact.
    - Verify step status updates in ProgressStepper.
  - **Scenario 2: Validation & Error Summary (`ERR-01`, `PERS-06`)**:
    - Trigger on-blur validation; verify green checkmark on valid fields.
    - Click Continue with empty required fields; verify `ErrorSummary` appears at top with focus and clicking error anchor focuses problem field.
  - **Scenario 3: Passport Expiry <6 Months Warning (`PERS-05`)**:
    - Enter expiry date 3 months in the future.
    - Verify `ExpiryWarning` appears; verify Continue is blocked until checkbox is checked.
  - **Scenario 4: Draft Persistence & Resumption (`STATE-04`)**:
    - Fill Stage 1 and Stage 2a.
    - Reload page / open fresh tab.
    - Verify "Continue Application" banner appears and clicking it drops user on Stage 2b.
