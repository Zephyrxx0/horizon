# Plan 03-02: Document Slot Card, Sub-Slots, Dual Camera/File Input & Quality Warning

## Goal

Develop the accessible UI primitives for document slot cards, multi-part sub-slots, dual mobile camera/file triggers, desktop dropzone, and quality warning override cards.

## Tasks

### 1. StatusBadge & QualityWarningCard Components

- Create `src/features/documents/StatusBadge.tsx`:
  - Renders upload status states:
    - `idle`: Unattached slot state.
    - `optimizing`: Animated spinner + "Optimizing image…".
    - `ready`: Green "✓ Ready" pill with formatted size (e.g., "1.4 MB") and image thumbnail (with zoom icon).
    - `error`: Inline red error message with specific reason and guidance.
  - Actions: "Replace" and "Remove" buttons with 48px touch targets.
- Create `src/features/documents/QualityWarningCard.tsx`:
  - Amber callout card (`#FFFBEB` background, `#B45309` border/text, alert triangle icon).
  - Copy: "⚠️ Image looks blurry or low-resolution. All text must be clearly readable to avoid rejection."
  - Primary button: "Retake Photo" (triggers camera/file selection).
  - Secondary button: "✓ Use This Image Anyway" (sets `isBlurWarningAcknowledged: true`).
- Create `src/features/documents/StatusBadge.test.tsx` and `src/features/documents/QualityWarningCard.test.tsx`.

### 2. DocumentSubSlot Component

- Create `src/features/documents/DocumentSubSlot.tsx`:
  - Manages sub-uploaders within a multi-part card (e.g. "Passport Bio Page (Pages 1–2)" and "Passport Address Page (Pages 35–36)").
  - Renders sub-title, specific page instructions, independent dual camera/file triggers, drag-and-drop listener, and `StatusBadge`.
  - Integrates `QualityWarningCard` when an uploaded sub-attachment triggers blur warnings.
- Create `src/features/documents/DocumentSubSlot.test.tsx`.

### 3. DocumentSlotCard Component

- Create `src/features/documents/DocumentSlotCard.tsx`:
  - Reuses `src/components/ui/Card.tsx`.
  - Header: Slot title, Mandatory/Optional badge, "View sample & guidelines" action link, and template download button if applicable.
  - Body: Plain-language instructions ("Keep phone flat", "All 4 corners visible").
  - Content: If slot has `subSlots`, renders child `DocumentSubSlot` list. Otherwise renders single slot uploader with dual mobile camera/file triggers and desktop dropzone.
  - Attachments list: Shows thumbnail, filename, size, ready badge, and replace/remove buttons.
  - Integrates `QualityWarningCard` for single slot uploads.
- Create `src/features/documents/DocumentSlotCard.test.tsx` testing mobile camera trigger, file input, drag-and-drop events, replace/remove actions, and axe a11y compliance.
