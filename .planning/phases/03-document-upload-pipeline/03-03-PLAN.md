# Plan 03-03: Sample Guidance Sheet, Document Preview Sheet & Template Generator

## Goal

Build the sample guidance visual modal, high-resolution document preview modal/sheet with zoom/pan and PDF handling, and client-side downloadable template generator.

## Tasks

### 1. Template Generator & Download Button

- Create `src/features/documents/templates.ts`:
  - `generateDocumentTemplateBlob(templateType: 'sponsorship' | 'employment_noc' | 'financial_declaration'): Blob`:
    - Generates pre-formatted official document templates with clear placeholder fields (e.g. `[Applicant Name]`, `[Passport Number]`, `[Employer Name]`, `[Dates of Travel]`).
  - `downloadTemplate(templateType: 'sponsorship' | 'employment_noc' | 'financial_declaration', fileName: string): void`:
    - Creates download anchor element and triggers browser download.
- Create `src/features/documents/TemplateDownloadButton.tsx`:
  - 48px accessible button rendering "Download template (PDF/Text)" with download icon.
- Create `src/features/documents/templates.test.ts` and `src/features/documents/TemplateDownloadButton.test.tsx`.

### 2. DocumentPreviewSheet Component

- Create `src/features/documents/DocumentPreviewSheet.tsx`:
  - Reuses `src/components/ui/Sheet.tsx`.
  - Accepts `attachment: DocumentAttachment | null`, `blob?: Blob`, `isOpen: boolean`, `onClose: () => void`.
  - For image files:
    - Renders high-res image canvas/element with zoom in/out controls, reset zoom, and pan/drag support.
    - Displays legibility checklist ("Check that passport number, name, and dates are sharp and readable").
  - For PDF files:
    - Renders embedded `<object>` or `<iframe>` PDF viewer with fallback download button.
  - Footer actions: "Replace file" and "Done / Close".
- Create `src/features/documents/DocumentPreviewSheet.test.tsx` testing open/close, focus management, zoom controls, and axe a11y.

### 3. SampleGuidanceSheet Component

- Create `src/features/documents/SampleGuidanceSheet.tsx`:
  - Reuses `src/components/ui/Sheet.tsx`.
  - Accepts `slotId: DocumentSlotId | null`, `isOpen: boolean`, `onClose: () => void`.
  - Renders visual guide for the selected slot:
    - **Passport**: Annotated sample showing Bio Page 1-2, clear photo, signature, and highlighted Machine Readable Zone (MRZ).
    - **Photograph**: Side-by-side comparison ("✓ Good: White background, forward facing, bright lighting" vs "✗ Bad: Glare on glasses, dark shadows, tilted head, selfies").
    - **Address Proof**: Sample utility bill/Aadhaar card with address highlighted.
    - **Sponsorship / NOC**: Sample letter layout with official letterhead.
  - Photography tips list ("Shoot in daylight", "Keep phone parallel to paper", "Include all 4 borders").
- Create `src/features/documents/SampleGuidanceSheet.test.tsx`.
