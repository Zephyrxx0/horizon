# Plan 03-01: Document Requirements Catalog, Quality Heuristics & Storage Layer

## Goal

Build the foundational data structures, visa-specific document requirements catalog, client-side Canvas Laplacian edge-contrast blur heuristic engine, and high-level storage integration layer that drives the document upload pipeline.

## Tasks

### 1. Document Types & Requirements Catalog

- Create `src/features/documents/types.ts`:
  - `DocumentSlotId`: `'passport'` | `'photo'` | `'address_proof'` | `'sponsorship_letter'` | `'flight_itinerary'` | `'bank_statement'` | `'employment_noc'`
  - `DocumentSubSlotId`: `'passport_bio'` | `'passport_address'`
  - `DocumentSlotDefinition`: `id`, `title`, `description`, `instructions`, `isMandatory`, `allowedMimeTypes`, `maxSizeBytes`, `subSlots?`, `sampleType?`, `templateType?`
  - `DocumentAttachment`: `docId`, `slotId`, `subSlotId?`, `fileName`, `originalSize`, `compressedSize`, `mimeType`, `uploadedAt`, `isBlurWarning`, `isBlurWarningAcknowledged`
  - `QualityAssessmentResult`: `isBlurry`, `score`, `width`, `height`, `aspectRatio`
- Create `src/features/documents/requirements.ts`:
  - `DOCUMENT_SLOT_DEFINITIONS`: Record of all document slots with explicit requirements:
    - **Passport**: Mandatory. Sub-slots: Bio Page (Pages 1–2) + Address Page (Pages 35–36). Allowed: JPG, PNG, PDF.
    - **Photograph**: Mandatory. 4x6cm / 35x45mm white background photo. Allowed: JPG, PNG.
    - **Proof of Address**: Mandatory for long-term/student, optional for tourist.
    - **Sponsorship / Invitation Letter**: Optional/conditional. Has downloadable template.
    - **Employer NOC**: Optional/conditional. Has downloadable template.
    - **Financial Declaration / Bank Statement**: Optional/conditional. Has downloadable template.
  - `getDocumentSlotsForVisa(visaType: string)`: Returns `{ mandatory: DocumentSlotDefinition[]; optional: DocumentSlotDefinition[] }`.
- Create `src/features/documents/requirements.test.ts`.

### 2. Canvas Laplacian Blur & Quality Heuristic Engine

- Create `src/features/documents/quality.ts`:
  - `assessImageQuality(file: Blob): Promise<QualityAssessmentResult>`:
    - If `application/pdf`, return `{ isBlurry: false, score: 999, width: 0, height: 0, aspectRatio: 0 }`.
    - Create `ImageBitmap` from file. Check dimensions: if `width < 600 || height < 600`, flag `isBlurry: true`.
    - Draw to 256×256 offscreen Canvas. Convert to grayscale.
    - Compute 3×3 discrete Laplacian operator over grayscale pixels:
      `laplacian = gray[top] + gray[bottom] + gray[left] + gray[right] - 4 * gray[center]`.
    - Compute variance of Laplacian. If `variance < 100`, flag `isBlurry: true`.
  - `checkPhotoAspectRatio(width: number, height: number): { isCompliant: boolean; message?: string }`:
    - Checks 4:6 or 35:45 ratio (within ±15% tolerance).
- Create `src/features/documents/quality.test.ts` testing sharp synthetic images, low-res images, blurry images, and PDFs.

### 3. Document Processing & Storage Adapter

- Create `src/features/documents/storage.ts`:
  - `processAndStoreDocument(file: File, slotId: DocumentSlotId, subSlotId?: DocumentSubSlotId): Promise<{ attachment: DocumentAttachment; quality: QualityAssessmentResult }>`:
    - Validate file format: allow `image/jpeg`, `image/png`, `application/pdf` only. Reject unsupported types.
    - Validate file size: reject files > 10MB before compression.
    - Run `assessImageQuality(file)`.
    - Run `compressToBudget(file, 2 * 1024 * 1024)` to compress images to ≤2MB.
    - Generate unique `docId = `${slotId}_${subSlotId || 'main'}_${Date.now()}`.
    - Save compressed blob in IndexedDB using `saveDocument(docId, compressedBlob)`.
    - Construct and return `DocumentAttachment` metadata.
  - `removeStoredDocument(docId: string): Promise<void>`:
    - Calls `deleteDocument(docId)`.
  - `retrieveStoredDocument(docId: string): Promise<Blob | undefined>`:
    - Calls `getDocument(docId)`.
- Create `src/features/documents/storage.test.ts`.
