<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User keystrokes → machine events → localStorage | Untrusted input crosses into persisted state |
| Persisted envelope → createActor restore | Tampered/stale storage replays into the running app |
| localStorage contents → DOM render | Stored answers render back into components |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-12 | Tampering | Malformed/hostile persisted snapshot (prototype pollution vector) | mitigate | loadAnswersEnvelope validates schemaVersion + minimal shape using own-property checks before createActor; invalid envelopes discarded safely (Pitfall 2 protocol) |
| T-1-13 | Information Disclosure (XSS sink) | Answers rendered back into DOM | mitigate | React escaping + repo-wide dangerouslySetInnerHTML ban; inputs are controlled values, never injected HTML |
| T-1-14 | Denial of Service (data) | QuotaExceededError silently dropped | mitigate | saveAnswersEnvelope try/catch → false → SaveState 'error' → UI-SPEC storage-error block + Retry; honesty mandated by SC#2 |
| T-1-15 | Denial of Service | Async writes cancelled during teardown losing data | mitigate | Flush path is synchronous localStorage only; IDB never used in flush (D-02 rationale) |
| T-1-16 | Repudiation | Indicator claiming false safety | mitigate | SaveState transitions driven exclusively by real setItem outcomes; E2E kill-the-tab test polices the claim |
</threat_model>
