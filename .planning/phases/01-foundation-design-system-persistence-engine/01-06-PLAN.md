| Threat ID       | Category          | Component                                               | Disposition | Mitigation Plan                                                                                                                  |

| T-1-21          | Tampering         | Arbitrary locale string written to documentElement.lang | mitigate    | changeLocale validates against the fixed six-code LOCALES allowlist before any DOM write or import                               |
| T-1-22          | Tampering (XSS)   | Interpolated values in future translated copy           | mitigate    | escapeValue:false is safe ONLY because React escapes — dangerouslySetInnerHTML ban stays repo-wide; i18n never receives HTML     |
| T-1-SC          | Tampering         | @fontsource/* packages entering tree                    | accept      | Already covered by plan 01's gated install + pins; no NEW installs in this plan                                                  |
| T-1-23          | Denial of Service | Locale-chunk import failure leaving blank UI            | mitigate    | fallbackLng 'en' + hasResourceBundle guard; failed dynamic import falls back to EN copy rather than key-spew (Pitfall 7 posture) |
| </threat_model> |
