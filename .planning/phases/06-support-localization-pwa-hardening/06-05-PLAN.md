# Plan 06-05: Assistive Technology Focus Management, A11yAnnouncer Live Regions, Whole-Journey axe-core & 3G CWV Hardening Gates

## Goal

Lock in the final quality and accessibility gates: dynamic screen reader announcements via `A11yAnnouncer`, focus management across all wizard stage transitions, comprehensive WCAG 2.1 AA validation with axe-core across every route, and throttled 3G Core Web Vitals performance verification.

## Tasks

### 1. Assistive Tech Live Announcer & Focus Engine

- D-15: Create `src/components/A11yAnnouncer.tsx`:
  - Visually hidden container with `aria-live="polite"` for step changes, save confirmations, and locale switches, and `aria-live="assertive"` for critical alerts.
- Create `src/components/A11yAnnouncer.test.tsx`.
- D-15: Update `src/components/ui/focus.ts`:
  - `focusStepHeading(stepId: string): void`: Smoothly focuses active stage `<h1>` or `ErrorSummary` on stage transitions.
- Integrate into `src/App.tsx`.

### 2. Whole-Journey Automated Accessibility Suite (WCAG 2.1 AA)

- D-16: Create `tests/a11y/journey-a11y.test.tsx`:
  - Integration suite rendering each stage (Visa Selection, Personal Identity, Personal Contact, Visa Specific, Documents, Review & Payment, Confirmation) and running `axe(container)` with WCAG 2.1 AA rule tags (`wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`).
  - Asserts 0 violations across all stages.
- D-16: Create `tests/e2e/journey-axe.spec.ts`:
  - Playwright E2E test scanning the live app during full journey walkthrough using `@axe-core/playwright`.

### 3. Throttled 3G Performance & Core Web Vitals Gate

- D-16: Create `tests/e2e/perf-3g.spec.ts`:
  - Emulates 3G network conditions (400ms latency, 400 kbps throughput) and 4x CPU slowdown.
  - Measures LCP (< 2.5s) and CLS (< 0.1).
  - Asserts zero eager Indic font downloads on initial English page load.

### 4. Full Suite Hardening Run

- Execute all unit, integration, a11y, and E2E verification suites.

## Verification

- `pnpm vitest run tests/a11y/` passes with 0 violations.
- `pnpm vitest run` passes all project unit/integration tests.
