# Plan 06-02: Six-Language Localization Dictionaries, Dynamic Indic Font Loader & Logical CSS

## Goal

Deliver high-fidelity translations across English, Hindi, Tamil, Telugu, Kannada, and Marathi across four modular namespaces (`common`, `wizard`, `help`, `errors`), ensure smooth on-demand Indic font loading, and enforce CSS Logical Properties for typography and layout integrity.

## Tasks

### 1. Translation Dictionaries across 6 Languages

- D-13: Create/update modular JSON files under `src/i18n/locales/{en,hi,ta,te,kn,mr}/`:
  - `common.json`: Navigation, buttons, save indicator modes (`offline`, `saved`), clear data dialog, language names.
  - `wizard.json`: All 5 stages, step titles, field labels, placeholders, guidance notes, fee labels, timeline statuses, checklist items.
  - `help.json`: FAQ categories, 18 curated questions/answers, helpline details, jargon definitions, support ticket form copy.
  - `errors.json`: Constructive error messages, passport expiry warning, format errors, quota errors, duplicate passport warning.

### 2. i18n Module & Type Definitions

- D-13: Update `src/i18n/i18next.d.ts` and `src/i18n/index.ts`:
  - Export `NAMESPACES = ['common', 'wizard', 'help', 'errors'] as const`.
  - In `changeLocale(lng)`: Dynamically load all 4 namespace bundles in parallel via `Promise.all`.
  - Update `document.documentElement.lang = lng` and persist selection to `localStorage`.
- Update `src/components/LanguageSwitcher.tsx` and `src/components/LanguageSwitcher.test.tsx`.

### 3. Dynamic Indic Font Loader & Typography Styling

- D-14: Update `src/fonts.ts`:
  - Dynamic imports for `@fontsource/noto-sans-devanagari` (for `hi`, `mr`), `@fontsource/noto-sans-tamil` (for `ta`), `@fontsource/noto-sans-telugu` (for `te`), and `@fontsource/noto-sans-kannada` (for `kn`).
  - Cache loaded fonts to prevent redundant injections.
- Create/update `src/fonts.test.ts`.
- D-14: Update `src/styles/theme.css`:
  - Enforce font family stack with `Nirmala UI` and `system-ui` fallback cascade.
  - Ensure relaxed line-heights (`1.6`) on text containers and inputs to prevent Indic diacritic clipping.

## Verification

- `pnpm vitest run src/i18n/ src/fonts.test.ts src/components/LanguageSwitcher.test.tsx` passes with 100% test success.
- `node scripts/check-font-budget.mjs` verifies zero eager Indic fonts in initial bundle.
