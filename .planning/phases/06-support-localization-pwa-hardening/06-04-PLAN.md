# Plan 06-04: Privacy Trust Architecture, Sensitive Field Micro-Cues & Public Device Storage Purge

## Goal

Anchor plain-language data privacy and trust throughout the application: a prominent pre-flight trust card before Stage 2, discrete lock micro-cues on sensitive inputs, a Review stage security seal, and a complete storage wipe engine for shared/cyber-café computers.

## Tasks

### 1. Storage Purge Utility

- D-07: Create `src/persistence/cleanup.ts`:
  - `clearAllDraftData(): Promise<void>`:
    - Purges all `localStorage` keys matching `visarethink.*`.
    - Clears the `idb-keyval` document store (`docStore`).
    - Resets session indicators.
- Create `src/persistence/cleanup.test.ts`.

### 2. Privacy Pre-Flight Card & Privacy Promise Sheet

- Create `src/features/trust/types.ts`:
  - Data privacy guarantees and security level types.
- D-05: Create `src/features/trust/PrivacyTrustCard.tsx`:
  - Pre-flight card with 3 core pillars (Local storage only, Zero 3rd-party sharing, Encrypted document processing) + `"Read our Privacy Promise"` trigger.
- Create `src/features/trust/PrivacyTrustCard.test.tsx`.
- D-05: Create `src/features/trust/PrivacyPromiseSheet.tsx`:
  - Accessible `Sheet` detailing data retention, local isolation, document disposal, and user rights.
- Create `src/features/trust/PrivacyPromiseSheet.test.tsx`.

### 3. Micro-Trust Cues, Security Seal & Shared Device Reset Modal

- D-06: Update `IdentityStep.tsx` and `ContactStep.tsx`:
  - Add lock micro-cues (`🔒 Kept secure on this device until final submission`) under sensitive fields.
- D-08: Create `src/features/trust/SecuritySealBadge.tsx`:
  - Rendered on `ReviewScreen.tsx` before payment: application integrity seal, TLS 1.3 simulation indicator, and MEA standards notice.
- Create `src/features/trust/SecuritySealBadge.test.tsx`.
- D-07: Create `src/features/trust/ClearDataModal.tsx`:
  - 2-step confirmation dialog with backup code reminder; executes `clearAllDraftData()`, shows success toast, and resets wizard machine to stage 1.
- Create `src/features/trust/ClearDataModal.test.tsx`.
- D-07: Update `src/components/AppShell.tsx` to add `"Reset / Clear Data"` in header and footer.
