# Plan 06-03: Persistent Help & Support Escape Hatch, Searchable FAQ Sheet & Contextual Jargon Tooltips

## Goal

Provide a persistent, accessible slide-over FAQ support sheet accessible from any screen without losing form state, paired with tap-to-expand contextual jargon tooltips and visual passport bio-page diagrams.

## Tasks

### 1. Support Data Model & FAQ Catalog

- Create `src/features/support/types.ts`:
  - `FaqCategory`: `'all' | 'passport' | 'documents' | 'payment' | 'tracking' | 'general'`
  - `FaqItem`: `{ id: string; category: FaqCategory; questionKey: string; answerKey: string; tags: string[] }`
  - `SupportTicket`: `{ ticketId: string; applicantName: string; contactInfo: string; category: string; description: string; createdAt: string }`
- D-03: Create `src/features/support/faqCatalog.ts`:
  - Curated 18 questions across visa categories with fuzzy keyword search filter function `searchFaqs(query, category, t)`.
- Create `src/features/support/faqCatalog.test.ts`.

### 2. FAQ Slide-over Sheet & Support Ticket Modal

- D-01: Create `src/features/support/FaqSheet.tsx`:
  - Accessible slide-over `Sheet` (title: `"Help & Frequently Asked Questions"`).
  - D-03: Search input with clear button and live result counter.
  - D-03: Category pill filter buttons (`All`, `Passport`, `Documents`, `Payment`, `Tracking`, `General`).
  - Accordion list with `aria-expanded` and keyboard navigation.
  - D-04: In-sheet support card: Helpline (`1800-VISA-HELP`), hours (`9 AM - 6 PM IST`), and `"Submit Support Query"` action button.
- Create `src/features/support/FaqSheet.test.tsx`.
- D-04: Create `src/features/support/SupportTicketModal.tsx`:
  - Accessible modal to submit simulated query or request callback; generates ticket ID (e.g. `TKT-1800-91823`) with toast alert.
- Create `src/features/support/SupportTicketModal.test.tsx`.

### 3. Jargon Tooltips & Passport Diagram

- D-02: Create `src/features/support/PassportDiagram.tsx`:
  - Accessible SVG illustration of the Indian passport biographical page highlighting Zone 1 (Surname / Given Name), Zone 2 (Passport Number & Place of Issue), and Zone 3 (Issue & Expiry Dates).
- Create `src/features/support/PassportDiagram.test.tsx`.
- D-02: Create `src/features/support/JargonTooltip.tsx`:
  - 48px touch target `(i)` button that toggles an inline micro-popover card with plain-language explanation and optional diagram.
- Create `src/features/support/JargonTooltip.test.tsx`.
- D-02: Update `src/components/ui/Field.tsx`:
  - Add optional `tooltip` / `jargonKey` prop to `Field` and `FieldLabel`.
- Wire `JargonTooltip` to:
  - `IdentityStep.tsx` (`givenName`, `surname`, `passportNumber`, `dateOfIssue`, `placeOfIssue`).
  - `CardPaymentForm.tsx` (`cvv`, `expiryDate`).
  - `UpiPaymentForm.tsx` (`vpa`).
- D-01: Update `src/components/AppShell.tsx` with floating bottom helper `(?)` button and header `"Help"` link.
