# Plan 06-01: PWA & Service Worker Foundation, Offline Resilience & Network Transition Engine

## Goal

Configure `vite-plugin-pwa` with Workbox caching rules that prevent stale-shell bugs, establish the reactive online/offline network monitor, and provide reassuring offline UX (`OfflineBanner`, `SaveIndicator` offline mode, `InstallPromptBanner`, and `OfflineGuardModal`).

## Tasks

### 1. PWA Plugin & Workbox Service Worker Setup

- D-10: Add `vite-plugin-pwa` and `workbox-window` to `package.json` devDependencies.
- D-10: Configure `VitePWA` in `vite.config.ts`:
  - `registerType: 'autoUpdate'`
  - Web App Manifest: `name: 'VisaReThink — Reimagined Indian Visa Portal'`, `short_name: 'VisaReThink'`, `theme_color: '#3730a3'`, `background_color: '#f7f7fa'`, `display: 'standalone'`, icons config.
  - Workbox runtime caching:
    - `NetworkFirst` (3s timeout) for navigation (`request.mode === 'navigate'`) to eliminate stale-shell caching bugs on redeploy.
    - `StaleWhileRevalidate` for `assets/*.{js,css}` and images.
    - `CacheFirst` (1-year TTL) for Indic font subsets and woff2 files.

### 2. Reactive Network Status & Install Hooks

- Create `src/features/pwa/types.ts`:
  - `NetworkStatus`: `{ isOnline: boolean; wasOffline: boolean; isReconnected: boolean }`
  - `BeforeInstallPromptEvent` interface.
- D-09: Create `src/features/pwa/useNetworkStatus.ts`:
  - Listen to `window.addEventListener('online')` and `'offline'`.
  - Dispatch toast notification on reconnect (`"🌐 Connection restored — cloud draft synced"`).
- Create `src/features/pwa/useNetworkStatus.test.ts`.
- D-11: Create `src/features/pwa/useInstallPrompt.ts`:
  - Capture `beforeinstallprompt`, prevent default, and provide `promptToInstall()`.
- Create `src/features/pwa/useInstallPrompt.test.ts`.

### 3. Ambient Offline Banner, Offline Guard & SaveIndicator Mode

- D-09: Create `src/features/pwa/OfflineBanner.tsx`:
  - Top ambient notification card (`role="status"`, amber palette): `"⚠️ You are offline — all answers and documents remain safely saved locally on this phone"`.
- Create `src/features/pwa/OfflineBanner.test.tsx`.
- D-11: Create `src/features/pwa/InstallPromptBanner.tsx`:
  - Non-intrusive button in `AppHeader` + post-Stage 1 contextual card explaining offline access benefits.
- Create `src/features/pwa/InstallPromptBanner.test.tsx`.
- D-12: Create `src/features/pwa/OfflineGuardModal.tsx`:
  - Accessible `Sheet`/Modal displayed if payment submission is attempted offline: explains draft safety and requests reconnect to submit.
- Create `src/features/pwa/OfflineGuardModal.test.tsx`.
- D-09: Update `src/components/SaveIndicator.tsx`:
  - Support `'offline'` status displaying amber `"Saved Offline"` badge when `!isOnline`.
- Update `src/components/SaveIndicator.test.tsx` and `src/components/AppShell.tsx`.
