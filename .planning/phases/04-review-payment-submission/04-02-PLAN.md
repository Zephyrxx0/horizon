# Plan 04-02: Review Summary Cards, Deep-Link Round-Trip Editing & Sticky Banner

## Goal

Implement the check-answers summary interface for Stage 4: structured per-stage summary cards (`StageReviewCard`), deep-link round-trip step editing with a sticky top banner (`EditingBanner`), document preview chip integration, and the mandatory applicant accuracy declaration checkbox.

## Tasks

### 1. Stage Review Summary Card

- Create `src/features/review/StageReviewCard.tsx`:
  - Reuses `Card` design system primitive with `p-6` padding.
  - Header: Stage number badge, Stage title (e.g., "Stage 1: Visa Selection", "Stage 2: Personal Details", "Stage 3: Uploaded Documents"), and an accessible "Edit" `Button` (variant: outline/ghost, ≥48px touch target).
  - Body:
    - Renders readable 2-column key/value pairs for entered answers (Displaying clean labels and formatted values).
    - For Stage 3 (Documents): Renders document chips with thumbnails, original file names, formatted sizes (e.g. "1.2 MB"), "✓ Ready" green pills, and a click handler opening `DocumentPreviewSheet`.
  - Accessible `aria-label` on edit triggers: `"Edit Stage 1: Visa Selection"`.
- Create `src/features/review/StageReviewCard.test.tsx` testing render of text fields, document attachments, edit button clicks, and axe accessibility compliance.

### 2. Sticky Editing Banner

- Create `src/features/review/EditingBanner.tsx`:
  - Positioned at `sticky top-0 z-40` with `#FFFBEB` amber background and subtle border.
  - Left content: Active editing indicator ("✏️ Editing {{stageName}} — Your changes are saved automatically").
  - Right content: 48px touch-target primary button "✓ Return to Review" that dispatches `RETURN_TO_REVIEW` to the wizard machine.
  - Responsive: Stacks neatly or displays compact layout on mobile screens (<640px).
- Update `src/components/AppShell.tsx` or `src/App.tsx` to render `EditingBanner` when `returnToReview` is active.
- Create `src/features/review/EditingBanner.test.tsx`.

### 3. Applicant Declaration & Error Integration

- Create `src/features/review/DeclarationCheckbox.tsx`:
  - Accessible `Checkbox` wrapping: `"I declare that all information provided is true and documents uploaded are authentic."`
  - Inline error banner and focus management if submitted while unchecked.
  - Dispatches `ANSWER_CHANGED` with `fieldId: 'declarationConfirmed'`.
- Create `src/features/review/DeclarationCheckbox.test.tsx`.

## Verification

- `pnpm vitest run src/features/review/StageReviewCard.test.tsx src/features/review/EditingBanner.test.tsx src/features/review/DeclarationCheckbox.test.tsx` passes with 100% test success and zero axe violations.
