# Plan 04-03: Payment Method Selectors, Checkout Forms, Fee Breakdown Card & Scenario Controller

## Goal

Build the checkout and payment method selection interfaces for Stage 4: itemized fee breakdown card with trust messaging (`FeeBreakdownCard`), payment method selection (`PaymentMethodSelector`), method-specific input forms (UPI ID/QR, Cards with auto-formatting, Netbanking with Indian banks), and the test scenario controller bar (`PaymentScenarioBar`).

## Tasks

### 1. Fee Breakdown Card

- Create `src/features/review/FeeBreakdownCard.tsx`:
  - Reuses `Card` primitive with `p-6` padding.
  - Line items:
    - Visa Processing Fee: formatted rupees (e.g. `₹2,000` or `₹3,500`).
    - Government Visa Fee: `₹5,000`.
    - Platform & Technology Fee: `₹1,500`.
  - Divider with bold Total: `₹8,500` in 24px/600 text.
  - Trust pill: `✓ Zero hidden charges` in green badge (`#F0FDF4` background, `#166534` text).
- Create `src/features/review/FeeBreakdownCard.test.tsx`.

### 2. Payment Method Selector & Method Forms

- Create `src/features/review/PaymentMethodSelector.tsx`:
  - `RadioCard` group for `upi`, `card`, `netbanking` with brand logos (GPay, PhonePe, Paytm, RuPay, Visa, Mastercard, SBI, HDFC).
  - ≥48px touch targets, keyboard navigation, and `aria-label` attributes.
- Create `src/features/review/UpiPaymentForm.tsx`:
  - Mode toggle: "UPI ID / VPA" vs "Scan QR Code".
  - VPA mode: Input field for VPA with auto-suffix chip buttons (`@okhdfcbank`, `@okaxis`, `@paytm`, `@ybl`) that append suffix on click.
  - QR Code mode: Scannable mock SVG QR Code with simulated auto-confirm timer and timer countdown indicator.
- Create `src/features/review/CardPaymentForm.tsx`:
  - Card Number input with `formatCardNumber` (4-4-4-4) and brand logo indicator.
  - Expiry Date input with `formatCardExpiry` (MM/YY).
  - CVV input with `formatCvv` (3-4 digits) and masked characters.
  - Name on Card input.
- Create `src/features/review/NetbankingForm.tsx`:
  - 6 popular bank quick cards (State Bank of India, HDFC Bank, ICICI Bank, Axis Bank, Kotak Mahindra Bank, Punjab National Bank).
  - Searchable `Select` for all other Indian commercial banks.
- Create unit/component tests for each form component.

### 3. Payment Scenario Controller Bar

- Create `src/features/review/PaymentScenarioBar.tsx`:
  - Discreet test bar in payment footer or collapsible debug panel.
  - Radio pills for:
    - "✓ Success (Default)"
    - "⚠️ Card Declined"
    - "⏳ Bank Timeout / Pending"
    - "❌ Network Error"
  - Calls `setMockScenario('payment', scenario)` on change and updates test badge.
- Create `src/features/review/PaymentScenarioBar.test.tsx`.
