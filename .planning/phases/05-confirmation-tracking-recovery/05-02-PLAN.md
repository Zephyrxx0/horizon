# Plan 05-02: Confirmation Stage Cards (Reference, Timeline, Checklist & Notifications)

<objective>
Build the primary UI cards for Stage 5 Confirmation:
1. `ReferenceCard`: Prominent reference number banner (`VR-YYYY-XXXXXX`), 1-tap copy button with toast feedback, and WhatsApp / Web Share buttons (CNFRM-01, TRCK-03).
2. `StatusTimelineCard`: Vertical status timeline with human-readable dates, expected durations, next actions, and an interactive demo scenario bar (`[Advance Status]`, `[Simulate Info Request]`, `[Simulate Approval]`) dispatching live status change toast alerts (CNFRM-02, TRCK-02).
3. `InterviewChecklistCard`: Visa-specific checklist engine (`checklist.ts`), interactive completion checkboxes ("X of Y ready"), consulate arrival guidelines, and dual `.txt` download / print export (CNFRM-03).
4. `SentNotificationsCard`: Expandable disclosure previewing the simulated SMS and Email templates dispatched on submission (CNFRM-04).
</objective>

<threat_model>

- **Threat:** Interactive checklist state causing unhandled layout shifts or inaccessible click zones on small mobile screens.
  - **Mitigation:** Minimum 48px touch targets on checkboxes, aria-checked attributes, and responsive single-column card layout.
- **Threat:** Unhandled print CSS causing clipped timeline or unreadable formatting when user prints the guide.
  - **Mitigation:** Dedicated `@media print` styling isolating checklist and receipt without navigation or action buttons.
- **Threat:** Demo scenario advances modifying state without screen reader announcements.
  - **Mitigation:** Wrap timeline status updates in `aria-live="polite"` region and dispatch accessible toast messages.
    </threat_model>
