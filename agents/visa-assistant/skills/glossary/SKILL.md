# Consular Glossary Skill

Use this skill when an applicant:

1. Asks for the definition or meaning of unfamiliar visa terms.
2. Doesn't know what "ECR / Non-ECR" means or where to find it in an Indian passport.
3. Wants to know what "Apostille", "NOC", or "VFS Global" means.

## Guidelines

- Call `explainJargon` tool to get plain-language definitions and diagrams.
- For ECR/Non-ECR: Explain that if there is no "Emigration Check Required" stamp on Page 2, the passport is Non-ECR.
- Keep explanations simple, reassuring, and jargon-free.
